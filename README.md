# Nathan Witt - Portfolio

Professional portfolio of Nathan Witt, second-year cybersecurity student at Strasbourg Ynov Campus.

- English: https://wittnathan24-lab.github.io/
- Français : https://wittnathan24-lab.github.io/fr/

Six selected projects, an EN / FR language switch, original interactive artwork and downloadable English and French CVs.

This repository contains only the portfolio's static files. The private projects are described in case studies; their source code is not included here. Collaborative work is credited in the project descriptions.

## Updates

GitHub Pages publishes the root of the `main` branch. Pushing an update automatically republishes the site. There is no build step or package installation.

- `index.html`: English page.
- `fr/index.html`: French page.
- `assets/main.js` and `assets/main-fr.js`: project descriptions and interface behaviour.
- `assets/style.css` and `assets/languages.css`: styling and responsive layouts.
- `assets/nathan-witt-cv.pdf` and `assets/nathan-witt-cv-fr.pdf`: public CV downloads.

Manrope and IBM Plex Mono are bundled with their SIL Open Font License notices in `assets`.
